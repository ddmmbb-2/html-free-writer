# HTML Free Writer｜自由排版 Word

HTML Free Writer 是一個用單檔 HTML 製作的離線 A4 排版工具。可以像排版軟體一樣，把文字框、表格、圖片和符號放到紙張上的任意位置，適合製作公告、表單、圖文操作手冊和列印教材。

編輯器、文件內容和內嵌圖片都可以存在同一個 HTML 裡。把檔案帶到另一台電腦，用瀏覽器開啟就能閱讀、繼續編輯或列印。

## 快速開始

1. 用瀏覽器開啟 `free-word.html`。初始範例可以直接拿來測試拖曳，也可以按 **新文件** 開始空白排版。
2. 從工具列加入文字框、表格、圖片或符號。點一下選取物件，拖曳即可移動，拉右下角可調整大小。雙擊文字框或表格可編輯內容。
3. 左側可切換或新增頁面。右側可直接輸入物件的 X、Y、寬、高，單位為 mm，也可以調整前後圖層。
4. 按 **另存 HTML** 下載含目前內容的新檔。另存的檔案預設進入閱讀模式，按 **編輯模式** 即可繼續修改。

## 排版功能

| 功能 | 操作方式 |
| --- | --- |
| 固定 A4 畫布 | 每頁為直式 210 × 297 mm。縮放只影響螢幕顯示，頁面與物件的實際尺寸維持原設定。 |
| 格線與吸附 | 可選 1、2、5 或 10 mm 格線間距。拖曳可吸附至頁邊距、頁面中心和其他物件的邊緣。按住 `Alt` 可暫停吸附。 |
| 文字框 | 支援標題、粗體、斜體、底線、對齊及項目清單。文字依框寬換行，超出框底會繼續顯示，可自行拉大框或重新排版。 |
| 表格 | 支援格內文字編輯、橫向與垂直合併、矩形範圍合併、左右或上下切分，以及增刪列與欄。 |
| 圖片 | 可選擇本機檔案或拖入畫布，並可移動、調整圖層、旋轉及拉伸。圖片隨文件存入 HTML。 |
| 向量符號 | 內建箭頭、方框、圓框、直線、虛線、星形和勾叉等 16 種 SVG 圖形，可換色、旋轉或調整尺寸。 |

### 合併或切分表格

點一下表格，在右側按 **選取儲存格**，再拖曳選取範圍或依序點選兩個端點。右側會依選取範圍啟用 **橫向合併**、**垂直合併** 或 **合併範圍**。合併會保留各格內容。要切成兩格時，選取單一格，再選 **直切成兩格**（左右）或 **橫切成兩格**（上下）。

### 旋轉圖片和符號

拖曳圓形旋轉把手，或在右側輸入角度。拖曳時按住 `Shift` 可每 15° 吸附。取消 **鎖定比例** 後，可以單獨調整寬度或高度。再次鎖定會沿用目前的比例，例如先把圓框拉成橢圓，再等比例放大。

### 貼上、存檔與列印

- 先點畫布再貼上，可用剪貼簿內容新增物件。雙擊進入文字框或表格後再貼上，可插入到目前的編輯位置。剪貼簿有 HTML 格式時，可保留常見的標題、清單及表格結構。
- **另存 HTML** 會把所有頁面、內嵌圖片和編輯器打包成同一檔案。要分享可繼續修改的版本，直接傳這個 HTML。
- **列印／PDF** 會開啟瀏覽器的列印視窗。輸出 PDF 時，在目的地選擇 **另存為 PDF**。若需要維持實際尺寸，請確認選用 A4 和 100% 比例。閱讀和輸出時，超出 A4 紙邊的內容會裁切。

### 快捷鍵

| 快捷鍵 | 功能 |
| --- | --- |
| `Ctrl+S` | 另存 HTML |
| `Ctrl+Z`／`Ctrl+Y` | 復原／重做 |
| `Esc` | 結束框內編輯，或取消選取 |
| 方向鍵／`Shift` + 方向鍵 | 選取畫布物件時，移動 1 mm／5 mm |
| `Delete` | 刪除選取的畫布物件 |

## 開發與 AI 協作

專案由原生 HTML、CSS 和 JavaScript 組成，直接開啟 `free-word.html` 即可測試，無需安裝依賴或執行建置。應用程式和文件資料在同一檔案內，文件資料放在 `document-data` 的 JSON 區塊。每頁存一組物件，物件位置和尺寸以 mm 為單位，陣列順序對應由下至上的圖層。表格合併使用原生 HTML 的 `rowspan` 和 `colspan`，向量符號由內建 SVG 路徑繪製。

請 AI 協助修改時，可以附上目前的 HTML，說明要改的操作入口、重現步驟和預期結果。也可以請它檢查修改後的單檔是否能重新開啟、復原和列印。

> 例如：請修改 `free-word.html` 的圖片拖曳。圖片在 150% 縮放、旋轉 30° 後，拉右下角仍要固定對角，並確認另存再開啟時保留相同位置與尺寸。

本專案由 AI 協助開發，功能依實際排版操作持續調整。
